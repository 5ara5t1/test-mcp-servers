# GNEWS MCP Server:
this uv python package contains a simple GNEWS mcp server. It can allow your MCP client for and read headlines from GNEWS.ios.

### Categories: 
 - general
 - world
 - nation
 - business
 - technology
 - entertainment
 - sports
 - science 
 - health

## methods. 
    - search_top_10_headlines: returns search results for the 10 latest headlines from a specified category (see above)
